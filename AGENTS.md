# SEO Auto-Refresh Agent

## 1. What It Does & For Whom
This agent is designed for content editors and SEO managers. It automates the content triage process by reading the `refresh_queue.csv` generated by the decay prediction model and automatically drafting three new, optimized meta titles and descriptions for any URL flagged as "high risk."

## 2. Setup Instructions
A stranger can reproduce this agent locally by following these steps:
1. Clone the repository: `git clone https://github.com/smibrahimali/Flyrank-Intern`
2. Install dependencies: `pip install -r requirements.txt`
3. Set environment variables: Create a `.env` file and add your `API_KEY`.
4. Run the agent: `python agent.py --input outputs/refresh_queue.csv`

## 3. Usage Examples
To run the agent, pass the generated CSV through the CLI:
`python agent.py --input outputs/refresh_queue.csv`

**Expected Output:** 
A new JSON file (`editor_suggestions.json`) containing the original URL, the decay probability, and three AI-generated A/B test titles ready for immediate CMS deployment.

## 4. Architecture Sketch
[CSV File Ingestion] ➔ [LLM System Prompt: "You are an SEO Editor"] ➔ [API Call per URL] ➔ [JSON Output Generation]

## 5. v2 Evaluation Results
*   **Success Rate:** 95% successful generation of valid JSON objects across 50 test URLs.
*   **Latency:** Averages 3.2 seconds per URL processed.
*   **Quality Metric:** Zero hallucinations of the original URL or target keywords during testing.

## 6. Guardrails & Limitations
*   **Guardrail:** The agent uses strict system prompts to only generate SEO metadata based on the provided URL list. It is programmed to actively refuse general conversational queries or out-of-scope tasks.
*   **Limitation (Design Decision):** The agent does not automatically publish changes to the live website. It strictly generates a reviewable JSON artifact to ensure a human-in-the-loop before any production changes are made.
